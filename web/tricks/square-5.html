Square ending in 5

Multiply the tens digit by one more, then write 25.

Skip this if it does not end in 5.

20 25

4 × 5 = 20, then write 25. That is 2025.

  1. 1
    The front part

    The tens digit is 4. 4 × (4 + 1) = 20.

  2. 2
    Write 25

    Write 25 after 20. That is 2025.

If the tens digit is 1, the front is one digit. 15²: 1 × 2 = 2, then 25, so 225.

Try one

25²

  1. The tens digit is 2. 2 × 3 = 6.
  2. Write 25 after 6. That is 625.
