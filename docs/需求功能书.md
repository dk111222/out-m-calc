## 1. 一句话定位

给**美国小学生家长**的每天约**四分钟**速算训练：孩子用凑十、补偿、拆数等技巧，把整个小学阶段的计算练到又快又准；家长看到**哪一招已经稳住、哪一招还要练**。

**押注：**

1. 家长要的是能从低年级用到五年级的短习惯，不是某一年的口诀包，也不是另一套数学课。
2. 孩子不靠宠物也肯每天打开。
3. 家长认的进度是技巧，不是金币。

---

## 2. 目标用户与场景

| 角色 | 关系 | 要完成的事 |
| --- | --- | --- |
| 美国家长（付钱） | 注册、付费、看进度 | 晚饭后每人约 4 分钟；能说出「姐姐的 ×11 拆开稳住了，弟弟的凑十还要练」 |
| 孩子 K–5（使用） | 点昵称做题 | 大键盘、错了有一句人话技巧、四分钟到点就停 |
| 老师 / 学区 | 下一阶段 | 班级码、完成次数与最弱技巧；合同与花名册更晚 |

**第一版销售对象：** 仅美国家长家庭订阅。  
**不做第一批：** 英格兰家庭、欧洲大陆、学区采购、在家教育单独包装。

### 人物（设计用）

- **玛雅**（四年级家长）：孩子口诀会背，但 39+28、24×5 仍要竖式；希望一个订阅覆盖两个孩子。
- **利奥**（一年级）：20 以内加减还在掰手指；需要大键盘和「先凑十」。
- **诺拉**（五年级）：会笔算，心算 199+46、3.4×10、16×25 会卡；可接受一行不计分草稿。

## 3. 市场空档与竞品边界

口诀类（XtraMath / TTRS / Rocket Math）停在事实与计时；全科或游戏类（IXL / Prodigy）太宽。

**空档：** 贯穿小学的技巧阶梯 + 做错只留一句可审核的技巧句 + 家长按「技巧稳否」看进度。

**Red flag：** 若 v1 仍带乘法表或秒数徽章，家长会拿去和 XtraMath $6/年、TTRS £9/年比价，**$59 站不住**。

**相对 NumBots：** 补偿、拆数别人已有。差异不是「独家有这两招」，而是「做错只留一句技巧 + 接到乘/部分积/小数 + 家长看技巧掌握」。

## 4. 范围总览

### 4.1 第一版（MVP）必做

| 模块 | 摘要 |
| --- | --- |
| 平台 | 英文响应式网页；**手机浏览器**优先；无需应用商店安装包 |
| 账户 | 家长注册；最多 3 个孩子；年级 K–5 |
| 练习 | 约 4 分钟技巧会话；整屏一题 + 数字键盘；无选择题 |
| 反馈 | 做错：算式 + 正确答案 + ≤12 英文词写死策略句 |
| 阶梯 | 技巧生成器（见第 6 节）；部分技巧可写一行不计分草稿 |
| 掌握 | 「稳了」/「还在学」；不展示反应时间与百分位 |
| 家长 | 首页卡片、技巧列表、最多钉住 5 条未稳技巧 |
| 付费 | 14 天试用不绑卡；$59/年（主）/$7.99/月（次）；网站结账 |
| 合规 | 导出 CSV、删除账户；不采通讯录/照片/位置/广告 ID |

### 4.2 下一阶段

- 英格兰 MTC 单独模式（25 题 × 6s，不进每日主环）
- 班级码（≤30 昵称；完成次数 + 最弱技巧；无公开榜、无花名册）
- 每周可退订短邮件；可打印弱项
- 同家庭内美/英范围切换
- 可选反应时间层（不进每日主画面）

### 4.3 再往后

- 学校合同与花名册集成（Clever / ClassLink / Wonde）
- 法/德界面与当地数字范围
- 分数、标准算法、长除
- 效力研究后再谈学校高价

### 4.4 明确不做（v1）

- 加法格 / 乘法格 / 整张口诀轨道；11、12 整表（仅留 ×11「×10 再加自身」）
- 可见计时环、按秒徽章、3/4/6 分钟档
- 开课前分置测验与 60/25/15 配比
- 系统朗读、语音作答、四位练习码
- 宠物、金币、宝箱、排行榜、老师视图
- 分数、几何、应用题、竖式、长除
- 大模型出题或批改
- 应用商店安装包（访谈若多数只要图标，可后包「仅练习环」，**付款仍在网站**）
- 印度市场、拍照批改（旁路调研，默认不开）

## 5. 屏幕与主流程

窄屏优先。键盘固定底部，题在上半屏。不依赖悬停。

| # | 屏幕 | 要点 |
| --- | --- | --- |
| 1 | 落地页 | 定位句：「每天四分钟，练凑十、补偿和拆数。」主按钮：开始 14 天（结束前不用付款）。次要：登录。价格不挡第一次练习。 |
| 2 | 注册 | 家长邮箱、密码 ≥10 位。必选勾选：我是家长/监护人；同意保存昵称与做题记录。记勾选时间与方式。无儿童邮箱。 |
| 3 | 添加孩子 | 昵称 1–16 字符（不当登录名）、年级 K–5；最多 3 个。保存后一句「从凑十开始」类提示 → 进第一次练习。不播视频。 |
| 4 | 谁来练 | 列出昵称，点入练习。无四位练习码。退出登录在页底。 |
| 5 | 练习 | 整屏一题、大号黑字、横式。数字键盘：0–9、退格、提交；需小数的招加小数点。答案非负，无负号键。标「可写一行」的招：答案上方草稿 “work”，≤16 字符，不计分。 |
| 6 | 做对 | 约 200ms 对勾，无声音奖励 → 下一题。 |
| 7 | 做错 | 同屏留算式、正确答案、一句技巧。继续按钮 1.5s 后可点。无红叉音效、无生命值。 |
| 8 | 本次结束 | 题数、对数、刚才那招「还在学」或「稳了」。按钮：再来一组（不自动续时）/ 给家长看。 |
| 9 | 家长首页 | 每个孩子一张卡。 |
| 10 | 技巧页 | 一条技巧的最近几次。 |
| 11 | 付款 | 试用结束后，下一次点「开始」才出现。 |
| 12 | 账户 | 导出、删除、取消续费。 |

### 主路径

1. **家长开始：** 落地页 → 注册勾选 → 添加孩子 → 直接第一次约 4 分钟。
2. **孩子第二天：** 已登录浏览器 → 点昵称 → 开始 → 结束摘要。
3. **家长看进度：** 首页 → 技巧列表 → 钉住最多 5 条未稳技巧。
4. **试用结束：** 再点开始 → 付费墙；不付费不可新会话，进度可看 30 天再冻结。

## 6. 练习环（核心算法规则）

- 计时从第一题出现起，满 **4 分钟**。到点先做完当前题再结束，不中途切断。
- 一次会话只**新开 1 种**技巧，该技巧出 **2–4** 题；其余来自年级上限内未稳技巧；家长钉住优先。

**出题顺序：**

1. 家长钉住且未稳的技巧，轮流抽，每种先 1 题。
2. 若本会话尚未新开技巧：抽阶梯上第一种尚未开始、且年级 ≤ 上限的技巧，先 2 题；时间够再补到最多 4 题。
3. 其余未稳技巧轮抽，直到 4 分钟。
4. 若除新技巧外没有别的未稳技巧：这 2–4 题做完就结束，不必凑满 4 分钟。

**年级：** 仅作出题上限与起始招，不宣称「达到年级水平」。一年级不抽表上标为二年级及以后的招；标 3–4 的三年级可抽。

**无首测：** 家长选年级 → 从该年级阶梯第一招开始。该年级及以下全稳 → 上限升一年，首页写「已升到 X 年级的第一招」（家长可改回）。五年级全稳 → 每次抽最久未练的已稳招共 4 题；错多可掉回「还在学」。

**错题间隔：** 同一技巧至少隔 4 题；不够隔开则提前结束。同一技巧在一个**美国东部日历日**错 3 次 → 当天停出，结束页留技巧句并写「明天再练这招」。

**离开页面：** 至少答过 1 题记为一次会话并结束；未答题不计数。不提供半途续题。

**语气：** 安静、短句、无角色养成。

## 7. 技巧阶梯（生成器表）

每一行是一个生成器。题在范围内随机，避免与上一题数字完全相同。策略句写死，≤12 英文词。草稿行只在标了的行出现。对错只看最终数字；草稿可空可错。

| 年级 | id | 出题 | 策略句 | 草稿 |
| --- | --- | --- | --- | --- |
| K | `split10` | 和为 2–10，缺一个加数，如 5=2+? | Find the other part. | 无 |
| K | `make10` | 1–9 凑 10，如 7+?=10 | Find what makes 10. | 无 |
| K | `teen` | 11–19 写成 10+几，如 18=10+? | A teen is 10 plus ones. | 无 |
| 1 | `make10b` | 一位数相加、和 11–18，如 8+6 | Make 10 first. | 无 |
| 1 | `near` | 相差 1 的两个一位数，如 6+7 | Use the double, then add 1. | 无 |
| 1 | `three` | 三个一位数，其中两个凑 10，如 2+6+4 | Make 10, then add the rest. | 无 |
| 1 | `pm10` | 两位数 ±10，如 34+10 | Only the tens digit changes. | 无 |
| 1 | `place` | 整十加一位数，和 ≤100，如 20+7 | Add the tens and the ones. | 可写一行 |
| 2 | `split100` | 两位数加两位数，和 ≤100，如 46+27 | Add the tens, then the ones. | 可写一行 |
| 2 | `comp` | 加 9 / 加 19 / 减 9，如 39+18、41−9 | 加 9：Add 10, then take 1.；39+18：Add 40, then take 1.；减 9：Subtract 10, then add 1. | 无 |
| 2 | `pm100` | 三位数 ±10 或 ±100，如 350+10 | Only one digit changes. | 无 |
| 3 | `x2` | 一位或两位数 ×2，到 50×2 | Multiplying by 2 is doubling. | 无 |
| 3 | `x5` | 一位或两位数 ×5，到 20×5 | Multiply by 10, then halve. | 无 |
| 3 | `x10` | 一位数 × 整十，如 9×80 | Multiply, then place the zero. | 无 |
| 3–4 | `dbl` | 两位数 ×4 或 ×8，如 27×4 | Double, then double again. | 可写一行 |
| 4 | `dist` | 两位数 × 一位数，如 39×7 | 30×7, then add 9×7. | 可写一行 |
| 4 | `mul11` | 两位数 ×11，如 32×11 | 32×10, then add 32. | 可写一行 |
| 4 | `hundreds` | 整百或整千相减，如 600−180 | Change only the digits that matter. | 无 |
| 5 | `pow10` | 整数或一位小数 ×/÷ 10 或 100，如 3.4×10 | Move the digits one place. | 可写一行 |
| 5 | `comp100` | 近整百加法如 199+46；一位小数 ×5 如 3.6×5 | 199：Think of 200, then take 1.；×5：Multiply by 10, then halve. | 可写一行 |
| 5 | `partial` | 友好 ×25，如 16×25 | 16×100, then divide by 4. | 可写一行 |

**除法：** 不单列。某乘法技巧已「稳了」后，才从它生成逆运算；id 加 `:div` 后缀，掌握分开记。不生成整张乘法口诀，不生成 12 的表。

## 8. 掌握状态

- **稳了：** 某一技巧最近 6 次尝试中 ≥5 次正确，且分布在 ≥2 个美国东部日历日。
- **还在学：** 其余情况。
- 做错时已展示策略句；无单独「提示」按钮。新尝试进入后重算最近 6 次；不足则掉回「还在学」。
- **不记录、不展示**反应时间；不按秒发徽章；不显示百分位；不写「达到年级水平」。

## 9. 家长端

每个孩子一张卡：

- 上次练习日期（未练过：「还没开始」）
- 近 7 个美东日历日会话次数
- 已稳数、还在学数；未出过的技巧单独「还没练」

技巧列表：中文名 + 英文策略句 + 状态。点开：最近最多 10 次对/错与日期。不显示毫秒、不显示草稿。

未稳技巧可**钉住最多 5 条**（第 6 条须先取消）。这是家长唯一能改变出题的入口。不能自建卷、不能挑单个数字。

设置仅昵称与年级。改年级立即生效：上限以上技巧不再出现；已稳记录保留。会话长度固定约 4 分钟。界面英文，地区不切换。

## 10. 账户、数据与隐私

### 数据字段

| 实体 | 字段 |
| --- | --- |
| 家长 | 邮箱、密码哈希、同意时间、同意方式、订阅状态 |
| 孩子 | 昵称、年级、所属家长（最多 3） |
| 技巧 | 稳定 id（如上表） |
| 尝试 | 孩子、技巧 id、对错、是否写了草稿、时间、会话 id；**不存毫秒** |
| 掌握 | 每孩子每技巧一枚状态 + 状态变化日期 |

草稿若存，仅作该次尝试字段；家长界面不显示、不分享。

不采集：通讯录、照片、精确位置、广告标识。除邮箱与昵称外无自由文本。

### 账户能力

- 导出名下全部孩子的尝试 CSV：日期、昵称、技巧 id、对错
- 删除孩子：同时删尝试与掌握，二次确认
- 删除家长账户：30 天内可登录撤销，到期后尝试与账号一并删除

### 隐私产品约束（非法律意见）

- COPPA：收集 13 岁以下个人信息前需可验证家长同意；试用期不采支付信息时，同意方式须律师确认（勾选 ≠ 可验证同意）
- 不做行为广告；不把记录卖给数据经纪
- 无儿童聊天；密码与支付仅家长侧
- 英/欧 v1 不卖，架构仍按家长同意设计

## 11. 付款与商业

| 项 | 规则 |
| --- | --- |
| 试用 | 注册起 14 天全功能，**不收卡** |
| 年费 | **$59** / 年，最多 3 孩（主按钮） |
| 月费 | **$7.99** / 月（次按钮） |
| 渠道 | 网站结账（建议 Stripe Checkout）；不进应用商店分成 |
| 续费 | 购买前写明自动续费、价格、下次扣款日；账户可取消，付过周期用到结束 |
| 试用结束 | 再点「开始」才出付款页；不付费不可新会话；进度可看 30 天再冻结；付费后从冻结处继续，掌握不重置 |
| 商业化禁区 | 无广告、无装扮、无内购、无能量条 |
| 价格兜底 | 若练得动但不愿付 59：先降到 **$39/年**，不加学科 |

**收入情景（假设，非市场数据）：** Y1 付费家庭 低 160 / 基准 1,500 / 高 10,000 → 约 $9.4k / $88.5k / $590k。拉开差距的主要是获客与试用转付费。

**上线后 KPI：**

1. 14 天内完成 ≥8 次会话的家庭比例 → 低则改练习环  
2. 上述家庭中留下年费的比例 → 低则试降价到 $39
