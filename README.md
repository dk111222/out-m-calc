# out-m-calc

美国 K–5 **计算技巧日课**（Calculation Trainer）：每天约四分钟，用凑十、补偿、拆数等技巧练速算；家长看到哪一招稳了；可导出 **PDF 练习卷**（同生成器）。

第一版形态：**手机浏览器网页**（不做应用商店安装包）。家长付费，孩子做题。
